# Running on Replit

This import keeps the original Python project structure and Quant Lab dashboard.

## Workspace preview

Use **Run** to start the **Quant Lab** workflow:

```sh
python -u -m src serve --host 0.0.0.0 --port 5000 --no-browser
```

Open the Preview to use the backtest, comparison, strategy builder, and guides.
The server permits Replit preview embedding only when bound to a non-loopback
address in a Replit development environment. API calls still require the
per-launch token generated by the existing server.

**Access warning:** this is a research dashboard, not a multi-user hosted
service. Anyone who can open its page can submit backtests and modify the shared
research session. Do not publish it or expose it to untrusted users without
adding authentication and resource limits.

## Dependencies and command-line use

Python 3.10 is configured. Project dependencies are declared in
`pyproject.toml`; `requirements.txt` additionally includes deep-learning,
boosting, and testing dependencies. Install project packages through Replit's
package tools. No Docker or virtual environment is needed.

Run commands from the repository root so they use the working-tree source:

```sh
python -m src demo
python -m src list models
python -m src explain "deflated sharpe"
python -m pytest tests/test_webapp.py
```

The demo and default universe use the imported cached market data. New ticker
requests use Yahoo Finance and therefore need network access and are subject to
provider availability/rate limits. Core dashboard use needs no API keys.
Optional Anthropic assistant features need their separate dependency and
`ANTHROPIC_API_KEY`; they are not configured as part of this setup.
