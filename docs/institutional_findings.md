# Institutional toolkit: exploratory findings

Generated by `python -m experiments.institutional_findings`. Real-data sections use the platform's 15 ETFs, 2006-01-03 to 2026-09-21. Sections marked **simulated** use synthetic markets built for this repository: they test the machinery against a known truth and say nothing about real markets. Nothing here was tuned, and a number reported once is an observation, not evidence.

## 3. Volatility and time-series models on real data

**One-day-ahead volatility forecasts, walk-forward** (GARCH-t refit every 252 days on data to the origin; EWMA with the RiskMetrics 0.94). QLIKE: lower is better. Squared returns are a noisy proxy, so small differences are not significant.

**ARIMA order selection on SPY daily returns (last 1,500 days), BIC:** best order (0, 0, 0); BIC differences between the top candidates are small, which is the formal statement that daily returns are close to white noise.

A AR(1) on a Treasury butterfly-like log-price combination (IEF - TLT/2 - SHY/2, last 1,500 days) gives phi = 0.9983: a persistent but stationary spread, half-life about 416 days; this is where ARMA structure lives, in spreads and yields rather than in returns.

SPY against the equal-weight book over the last 2,500 days: P(SPY better) = 0.36.


## 5. Machine learning models on the 15 ETFs (real data)

Cross-sectional long-short books from each model's forecasts (`forecast_stack`), net of costs, the same walk-forward protocol for every model. The deflated Sharpe counts the five variants as trials. None of the five has a net Sharpe worth trading: a model that does not beat the ridge has not found signal the ridge missed, and the ridge itself loses money here, so the honest summary is that price-only features carry little cross-sectional signal in 15 liquid ETFs at this horizon, however flexible the learner.
