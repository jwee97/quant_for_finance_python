# Report importer: root-cause audit of the cross-market failures

**Scope and honesty.** The seven original FY2020 PDFs were not available. Everything below was established by reproducing each failure class on **synthetic look-alikes**
(`tests/fixtures/real_like.py`: invented text and figures wherever the task gave none, the reference values where it did), running the *previous* code (commit `59f1417`, the last one before this work)
on the *final* fixtures, and following the execution path with the code in front of me. A failure that the synthetic file does not reproduce is listed as **not reproduced**; a cause that is plausible for the
real file but unconfirmed is listed as **suspected**. **No original filing has been processed.**

Before-results come from `benchmarks/fundamentals_importer/results/real_structures_before.json` (old code, final fixtures); after-results from `real_structures_after.json` or `python benchmarks/fundamentals_importer/real_structures.py`.

## The execution path that was audited (before)

`engine.extract` → `pdf_layout.extract` (words → rows → segments → tables) → `matcher.build` → `statements.classify` (title and lines vote) → **`statements.resolve_columns`** (period of each figure column) →
candidates by label (`taxonomy.Mapping.match`, whole-label match) → one value per (period, line) by `max(confidence, −page, −row)` → `checks.run` (reconciliations; a missing input produced *no result at all*) →
`engine.extract`: **if fewer than 4 lines were found, the whole document went to the legacy line-by-line reader** (`pdf.extract`), whose reading has no statement or column context.

## Findings that are not company-specific (and were confirmed in code)

1. **Positional date-to-column matching** (`resolve_columns`) is the common mechanism behind Toyota, Samsung and Singtel.
2. **A count of extracted lines decided whether to fall back**, and the fallback was the least context-aware reader (Samsung).
3. **A missing reconciliation input produced no check**, so "nothing failed" looked like success (Singtel/Tencent would have passed with half a balance sheet).
4. **Net income was one line for total and parent-attributable profit**, and adjusted lines were not excluded.
5. **Whole-label matching** broke on bilingual labels and on totals vs components.
6. **Unit and currency were table-level** (and the unit pattern knew `$ millions` but not `EUR millions`).
7. **A statement split over pages was two tables.**

Not confirmed (no synthetic reproduction): Apple's inconsistent periods; Tencent's "selected values correct, full accuracy unverified" (it was correct for the lines it had); ASML's exact "reconciliation failures" (reproduced
only as the unit/label failures above).
